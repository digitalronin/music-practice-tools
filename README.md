# Music Practice Tools

## [Random Note Sequencer](random-note-sequencer.html)

Presents notes in a random sequence with a metronome, allowing variable number of
beats per note, to play each note or chord for a given number of repetitions (e.g. 
once per string on guitar), or for a fixed amount of time before moving on.

## Guitar

### [Fretboard Trainer](guitar/fretboard-trainer.html)

Presents notes in a random sequence with a metronome, allowing 6
beats per note, to play each note on every string of the fretboard.
